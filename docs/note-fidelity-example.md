# 情報保持のレビュー用見本

R-18 / A-18、A-19 / T-24、T-25。以下はこの検証のために作成した架空の説明で、教材からの転記ではない。期待応答は手作業で作成した評価基準であり、モデルの実生成結果ではない。

## 入力原文

```text
[00:00:00] 今回は箱の残数処理と、二種類の図を説明します。
[00:00:20] 入力は箱の数nで、0以上の整数です。残数rにnを入れ、処理回数cは0にします。ループ前にrを表示します。
[00:00:35] rが0より大きい間、古いrをtに保存します。次にrをt引く1にし、cを1増やします。この順序で行います。rが0になったら終わり、cを表示します。
[00:00:50] nが2なら最初はrが2、cが0です。1回後はtが2、rが1、cが1。2回後はtが1、rが0、cが2となり、終了して2を表示します。nが0なら最初に0を表示し、ループを一度も実行せずcの0を表示します。
[00:01:10] 箱の配置図は箱を置く場所を示し、作業順序図は作業の前後関係を示します。
[00:01:30] この配置の名前は「らく配置」です。名前の認識は不明瞭ですが、同じ用途の箱を近くに置く配置です。
[00:01:45] 別の点検手順では、残数が3のとき終了します。
[00:01:55] 先ほどの別の点検手順は、残数が2のとき終了します。
[00:02:10] 次の手順は、まず札を用意します。その後の説明は次の部分へ続きます。
```

## 照合基準

| 観点 | 合格となる内容 | 不合格例 |
| --- | --- | --- |
| 初期化・出力 | nの範囲、r=n、c=0、ループ前の表示がある | 「変数を初期化する」だけ |
| 更新・終了 | tへの退避、rの更新、cの増分、終了と出力の順序が追える | 更新順序の省略・逆転 |
| 具体例 | n=2の推移とn=0の無反復を残す | 「トレースできる」という紹介だけ |
| 概念の区別 | 配置図と作業順序図の役割を分ける | 両方を場所の図として扱う |
| 不明語 | 配置の説明は残し、名称のみ要確認にする | 不明語を本文の正式名称にする、配置の説明を削除する |
| 矛盾 | 両時刻と数値の相違をchecksに残す | 一方の条件を正解として確定する |
| 分割境界 | 札の準備は残し、続く手順の不足を明示する | 後続の手順を創作する |
| 根拠時刻 | 各説明の実際の開始時刻に対応する | 目次00:00:00を本文へ流用する |

この見本は上記基準と人手で照合する。モックテストでは実プロンプトと原文の連結、期待応答の解析、コード・表・確認事項と時刻の表示までを確認する。意味の保持をモデルが実行するかは、A-19で別途実生成を評価する。実生成評価では手順・必要な例の欠落、誤断定、根拠のない補完、概念混同、時刻の不一致を原文箇所ごとに記録し、費用・打切りも確認する。
