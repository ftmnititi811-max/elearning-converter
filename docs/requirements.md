# 要件定義

目的：利用権限のあるMP4講義の音声を、Windows向けPython CLIで復習用Markdownに変換・ローカル保存する。FFmpegで音声抽出、faster-whisperで文字起こし、Gemini APIで記事化する。映像・字幕・スライド解析、話者分離、GUI、一括処理はMVP対象外。

## 要件と受入基準

授業ノートの情報保持（R-18 / A-18、A-19 / T-24、T-25）：話題の網羅だけでなく、原文を根拠に処理や説明を追えることを目標とする。原文にある入力・初期値・条件・更新順序・終了条件・出力と、理解に必要な具体例・トレースを保持する。別概念の定義を混同せず、不確かな用語・式・数値を本文で確定事項として扱わない。確認できる説明は残し、不明部分のみ時刻付きの確認事項へ分離する。根拠時刻は目次ではなく実際の説明に対応させる。

受入基準：架空の時刻付き原文と期待ノートを照合し、上記の情報が保持されること、原文にない手順・数式の補完がないことをレビューできる。既存のAPI・表示経路で期待ノートが欠落せず扱えることをオフライン検証する（A-18）。モデルの実生成品質は別途承認された実API評価で確認し、モック成功とは区別する（A-19）。

| ID | 要件 |
| --- | --- |
| R-18 | 原文で確認できる手順・必要な具体例・概念の区別を保持し、不確かな語や式を断定せず、実際の説明箇所の時刻を付ける。詳細と受入基準は上記の情報保持方針に従う。 |
| R-01 | CLIでMP4と出力先を指定。欠落・非MP4は理由付きで終了。 |
| R-02 | ffprobeで音声を検査し、FFmpegでモノラル16 kHz WAVへ抽出。 |
| R-03 | 日本語を既定にfaster-whisperで時刻付き認識。空結果は失敗。 |
| R-04 | APIで講義の流れに沿う授業ノートを生成。理解に必要な前提・理由・具体例を残し、用語は文脈で説明する。定型的な前置きや重複を省き、見出し・表は整理に役立つ場合だけ使う。段落末・箇条書き末などの不要な句読点を省き、文の境界や誤読防止に必要なものは残す。根拠時刻を保持し、音声にない補完・断定を避ける。不明点は要確認事項へまとめる。 |
| R-05 | UTF-8の <stem>.md と <stem>.transcript.md を保存。元MP4は変更しない。 |
| R-06 | 既存出力は --overwrite 時のみ置換。不完全記事を完成品として残さない。 |
| R-07 | Gemini APIキーは環境変数 `GEMINI_API_KEY` から読み、未設定時はプロジェクトルートの `.env` にある同名の値を読む。環境変数を優先し、キーと本文をログへ出さない。 |
| R-08 | 処理段階と失敗理由をCLIに示す。 |
| R-09 | --no-article はAPIキーなしで原文だけ出力。 |
| R-10 | 記事化失敗時は時刻付き原文を救済名で保存し、部分成功を明示する。既存ファイルは `--overwrite` なしで変更しない。 |
| R-11 | 文字起こし失敗時は失敗した段階と内部例外の種類を示し、キー・本文・入力内容を表示しない。 |
| R-12 | FFmpegで作成した16 kHzモノラルPCM WAVはPyAVの音声デコーダーを介さずに読み、faster-whisperへ渡す。 |
| R-13 | Gemini呼び出し失敗時はHTTPステータスと例外種別を安全に表示し、一時的な障害だけを上限付きで再試行する。キー・本文・生の例外メッセージは表示しない。 |
| R-15 | 正式名称・配布名を `elearning-converter`、短縮コマンドを `elconv`、Pythonパッケージ名を `elearning_converter` に統一する。READMEとCLIヘルプも同じ名称を使用する。 |
| R-14 | 既定のGeminiモデルは利用可能な現行モデルを指定し、モデル名と費用の確認方法をCLI・READMEに示す。モデル指定オプションは維持する。 |
| R-16 | 記事化プロンプトをプロジェクト直下の `prompts/article.md` に外部化し、Pythonを編集せずに変更できる。R-04の授業ノート形式を指示し、文字起こしだけを資料として送る方式を維持する。 |
| R-17 | 記事応答のJSON構造をAPI設定でも指定する。応答失敗は分割番号と固定の理由（生成打切り・ブロック・空応答・JSON構文・項目型・時刻形式）で識別し、キー・本文・生のAPIメッセージを表示・保存しない。不完全応答を記事として採用せず、形式不正の自動再送信は行わない。 |

Windows 11、Python 3.11以降、CPU環境を基準としFFmpegは別途導入。MP4/WAVは外部送信せず、記事化時に文字起こしテキストだけGemini APIへ送る。従量課金を明示する。教材の加工・共有は著作権と利用条件に従い、機密情報があればAPI送信前に確認する。記事は復習用下書きで、原音声と照合する。

仮定：日本語の音声付きMP4。モデル、分割長、再試行、記事の長さ、救済名は暫定値を仕様に記し、権利確認済み短尺講義で品質・時間・費用を評価する。料金上限、専門語・数式の精度目標は実測後に決める。実APIテストは課金のため実施前に利用者へ確認する。
